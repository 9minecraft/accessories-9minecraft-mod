# Accessories — Manage Extra Wearable Gear Slots

Accessories 9minecraft Mod provides a background system for extra equipment slots. It works as a base requirement for other mods that add wearable items like rings, capes, and belts. This mod does not add any items or blocks on its own. You only need it when another mod, like The Aether, asks for it. It groups all extra item slots into one clean menu screen so you can manage your gear easily.

It creates new slots in your inventory for rings, amulets, necklaces, belts, gloves, capes, and back items.

## What this build is

An unofficial rebuild of **Blodhgarm**, **chyzman**, **miscellaneouszeal**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
